# tttBirthday

A handcrafted birthday webpage for ttt. Pure HTML/CSS/JS with SVG illustrations.

**Latest version**: `vf4.html` — Great Vibes cursive handwriting opening animation + time-based sky island picker.

## Run

Open `vf4.html` directly in a browser. No server or build step needed.

## Features

- 🖊️ SVG stroke animation opening with Great Vibes cursive font
- 🏝️ Time-based sky system (dawn → noon → sunset → night)
- 🍰 SVG-drawn birthday cake with blow-detection candles
- 🎁 SVG gift box with 4-stage treasure hunt + memory card game
- 🌴 CSS art island decorations (palm trees, ocean waves, balloons)
- 🎆 Warm finale fireworks with line-by-line text reveal
- 📱 Mobile responsive
